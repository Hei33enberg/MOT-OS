# Realm

The Realm is the contributor community around this client, and the open ledger of who did the work.

One principle: **the crown holds the DNA, the realm holds the infrastructure.** The founder keeps the vision, the name, and the final word ([GOVERNANCE.md](../GOVERNANCE.md)). The community holds the client, the docs, the installers, the mirrors, the merge rights, and the credit.

The theme is flavor. The rights are the open-source rights in the right-hand column. Nothing on this page is equity, a token, or a promise of payment.

## What you can actually change

This repository is the **client**: installer, stdio bridge, examples, docs. MIT. The gate at `mcp.mot3r.com` is not here. A pull request improves what people install. It does not open the hosted service, and it does not ship product 0.3.9. The client version in tree is 0.3.4 until a release says otherwise.

## Roles

| Realm role | OSS equivalent | Rights | How you get it |
|---|---|---|---|
| **Citizen** | community member | read, open issues, join Discussions | show up |
| **Squire** | first-time contributor | a row in the ledger | first merged substantive pull request |
| **Knight** | recognized contributor | a row in the [Hall of Fame](../HALL_OF_FAME.md) | 3 or more substantive pull requests |
| **Baron / Baroness** | area maintainer | merge rights in one area | the path in [MAINTAINERS.md](../MAINTAINERS.md) |
| **Herald** | docs and voice | speaks for the community in public | named by the Crown, after sustained work |
| **Warden** | security researcher | Hall of Fame, security lane | an accepted report under [SECURITY.md](../SECURITY.md) |
| **The Crown** | founder / BDFL | vision, final word, trademark | [GOVERNANCE.md](../GOVERNANCE.md) |

## Levels

"Substantive" means a feature, a hard bug fix, or a deep refactor. A typo, a dependency bump, or a drive-by reformat does not count. The ledger is [community/realm.json](../community/realm.json). The human page is [HALL_OF_FAME.md](../HALL_OF_FAME.md).

| Level | Title | Criteria |
|---|---|---|
| **L0** | Citizen | joined. No barrier |
| **L1** | Squire | 1 merged substantive pull request, or sustained issue triage |
| **L2** | Knight | 3 or more substantive pull requests |
| **L3** | Baron / Baroness | 5 or more substantive pull requests in one area, across 3 or more months, plus review judgement |
| **L4** | Herald | talks, integrations, or docs that carry the project, named by the Crown |

An agent climbs the same ladder. A pull request written by an agent, or with one, counts the same as any other. The ledger records the account that signed the work. See [AGENTS.md](../AGENTS.md).

## Words you write in

Public text uses the mot lexicon. [words.md](./words.md) is the list. The ones that get people in trouble:

| Word | Use it for |
|---|---|
| **line** | the permanent agent, and every API name |
| **tunnel** | the same thing, drawn in the panel |
| **cable** | the model session |
| **mot** | the gate |
| **mot3r** | the panel and the installer |

Do not write "the platform". Do not write that `npx mot3r` installs 0.3.9.

## How to start

1. Read [CONTRIBUTING.md](../CONTRIBUTING.md).
2. Open an issue or a discussion on [Hei33enberg/MOT-OS](https://github.com/Hei33enberg/MOT-OS).
3. If you are bringing an agent, start at [AGENTS.md](../AGENTS.md). The agent follows the same bar as a person.

Security reports do not go in issues. [SECURITY.md](../SECURITY.md).

The cable dies. The line lives. MOM remembers.

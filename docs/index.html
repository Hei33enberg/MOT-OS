mot

mot gives an agent a permanent home. The agent is a line: address, memory, channels, persona. The model is a cable. Swap the cable, the line stays. In the panel a line is drawn as a tunnel. The API keeps the word line.

mot is the gateway. mot3r is the panel and the installer. One MCP endpoint: https://mcp.mot3r.com/mcp. This site is the client documentation. The hosted service is not open source.

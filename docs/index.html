mot

Permanent home for your AI agents. One line. One address. Memory that survives the model.

mot turns a chat model into an agent with a job: identity, inbox, mail, memory, and paid tools — on one key, in Claude Code, Cursor, Codex, VS Code, or any MCP host. The model is a cable. Swap it. The line stays.

You do not rent a prompt that forgets you overnight. You open a line (name@mot.email), wire it once, and every session plugs into the same home.

Start

  1. Key at mot3r.com/panel (test key free; line key when the agent is real).
  2. Set MOT_KEY and run the one-line installer from the README.
  3. Tell the host: Call line_attach.

Endpoint: https://mcp.mot3r.com/mcp. mot is the gateway. mot3r is the panel and the installer. This site is client documentation. The hosted service is not open source.

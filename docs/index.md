# mot docs

Client documentation for [MOT-OS](https://github.com/Hei33enberg/MOT-OS).

**mot** is the gateway. **mot3r** is the panel and the installer. A line is the agent that stays; in the panel that same thing is a tunnel; a cable is the model on the line right now.

| Surface | Version |
|---|---|
| Live gate `https://mcp.mot3r.com/mcp` | **0.3.9** — `initialize` on 2026-11-11, **97** tools on `tools/list` |
| npm client in this repo | **mot3r 0.3.4** — does not install 0.3.9 |

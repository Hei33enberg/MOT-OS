# mot docs

Client documentation for [MOT-OS](https://github.com/Hei33enberg/MOT-OS).

**mot** gives AI agents a permanent home: a **line** (identity, memory, channels) that survives the model. The model is a **cable**. Swap the cable — the line stays. **mot** is the gateway. **mot3r** is the panel and the installer.

Start: [mot3r.com/panel](https://mot3r.com/panel/) → key → wire a host → `line_attach`. Sales pitch + install: [root README](../README.md). The page GitHub Pages serves is [index.html](./index.html).
